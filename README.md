# 紙上逃跑 — 影片版

全螢幕相機辨識使用者提供的藍色牌背，將「背景是綠幕.mp4」的原始手繪動畫去除綠幕後貼合牌面。角色是二維影片，不是立體模型。影片靜音播放，相機畫面只在本機處理。

- 單段演出：掃到藍色牌背後直接播放原影片 1.15–9.85 秒，小人跑入、畫門、走入並關門。
- 只需一張牌；不再播放打招呼、指右邊與隱形，也不需要移開鏡頭切換卡片。
- 失去追蹤、開啟說明或照片、離開分頁會暫停。播放完不會自動循環；長按右下角雙箭頭一秒重置。手機若限制自動播放可按「繼續動畫」。

影片的 720×1280 比例保持不變，裁去上下空白並遮除右下角標記。GPU 依綠色色差建立透明度，保留黑色人物與白色門框。輸入影片不變，去背在網頁即時完成。

本機預覽：`python -m http.server 4173 --bind 127.0.0.1 --directory dist`。手機請用 HTTPS 網址開啟。使用相同藍色牌背、避免反光並讓完整牌背留在畫面裡。實際手機與實體牌辨識仍需現場彩排。

檢查：`node check.mjs`。MindAR 1.2.5、A-Frame 1.6.0 授權附於 dist/assets。

介面採 iPhone 相機配置。右下角雙箭頭輕點鏡像、長按一秒重置；滑離按鈕會取消長按。數位倍率同時縮放相機和人物。快門可儲存合成照片；右側六點切換九宮格，左側 ƒ 開啟說明。上方狀態圖示與錄影／人像為外觀文字。

開啟網頁即自動啟動相機；首次仍需允許瀏覽器相機權限。啟動失敗時顯示重新開啟按鈕。
